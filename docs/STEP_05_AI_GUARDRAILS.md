# Step 05 - AI Output Guardrails

## Problem
The LLM incorrectly reported eight validation checks
instead of six, confusing exceptions with checks.

## Solution
- Deterministic factual summaries generated by Python.
- AI recommendation selection restricted to approved labels.
- Evidence-based recommendation eligibility.
- Deterministic fallback for unsupported AI responses.
- Transparent commentary source tracking.

## Testing
- Incorrect numerical commentary rejected.
- Valid AI recommendation accepted.
- Unsafe recommendation rejected.
- Mandatory validation coverage preserved.
- All seven automated tests passed.

## Limitations
The system uses predefined recommendations rather than
unrestricted AI-generated interpretations.
Human review remains necessary.

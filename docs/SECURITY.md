# Security and Limitations

- Validation is read-only.
- Python computes the authoritative audit findings.
- AI-generated commentary requires human review.
- Mandatory fallback checks ensure validation coverage.
- CSV exports include basic formula injection mitigation.
- HTML report content is escaped.
- Sample data is synthetic.
- Do not publish confidential datasets or generated audit outputs.
- This experimental release has not undergone a comprehensive security audit.

# Security and Limitations

- Validation is read-only.
- Python computes the authoritative audit findings.
- Mandatory fallback checks enforce configured validation coverage.
- Numerical summaries are generated deterministically.
- AI recommendations are restricted to approved labels.
- Recommendation eligibility depends on verified audit evidence.
- Unsupported AI responses trigger a deterministic fallback.
- AI-selected and fallback execution sources are recorded.
- Human review remains necessary.
- CSV exports include basic formula injection mitigation.
- HTML report content is escaped.
- Sample data is synthetic.
- Do not publish confidential datasets or generated audit outputs.
- This experimental release has not undergone a comprehensive security audit.
